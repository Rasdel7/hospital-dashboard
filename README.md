# Hospital Management Dashboard 🏥

Healthcare analytics platform covering patient
flow, doctor performance and disease trends.

## Live Demo
[Click here](https://hospital-dashboard-llqukcurxfs6dtcg6tfvqv.streamlit.app)

## Features
- Patient overview with status and severity KPIs
- Monthly admission trends
- Department-level analytics
- Doctor performance scatter plots
- Disease and age group analysis
- Blood group distribution
- Revenue analytics with monthly trends

## Dataset
1000 synthetic patient records
10 departments, 12 months of data

## Tools Used
- Python, Streamlit, Plotly, Pandas

## How to Run Locally
pip install streamlit pandas numpy plotly
streamlit run app.py
